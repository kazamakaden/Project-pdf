# คู่มือผู้ดูแลระบบ

**ระบบพัสดุสำนักงาน & ใบขออนุมัติสั่งซื้อ — วิทยาลัยเทคนิคอุดรธานี**

> เอกสารนี้เขียนสำหรับ **ผู้ใช้งานทั่วไป** และ **ผู้ดูแลระบบ (แอดมิน)** ที่ไม่จำเป็นต้องมีพื้นฐานด้านโปรแกรมมิ่ง
> หากต้องการติดตั้ง/ดูแลเซิร์ฟเวอร์ ให้อ่าน [คู่มือติดตั้งและส่งมอบระบบ](./คู่มือติดตั้งและส่งมอบระบบ.md)

## 1. เว็บนี้ทำอะไรได้บ้าง

| ผู้ใช้ | สิ่งที่ทำได้ |
| --- | --- |
| **ผู้ใช้ทั่วไป** | ดู/ค้นหาสินค้า, ใส่ตะกร้า, กรอกชื่อผู้ขอ/หน่วยงาน, สร้างและดาวน์โหลด **ใบขออนุมัติสั่งซื้อ** เป็น PDF, ดูทำเนียบบุคลากร |
| **แอดมิน** | ทุกอย่างของผู้ใช้ทั่วไป + เพิ่ม / แก้ไข / ลบสินค้า, อัปโหลดรูป, นำเข้าข้อมูลตั้งต้น, **เพิ่ม/แก้ไข/ลบรายชื่อในทำเนียบบุคลากร** |

- **ตะกร้าสินค้า** และ **ธีมสว่าง/มืด** เก็บไว้ในเบราว์เซอร์ของแต่ละคน (ไม่กระทบคนอื่น)

## 2. การใช้งานสำหรับผู้ใช้ทั่วไป

### 2.1 ดูและค้นหาสินค้า
1. เปิดเว็บ → หน้าแรกคือ **แคตตาล็อกสินค้า**
2. พิมพ์คำค้นในช่องค้นหา (เช่น "ปากกา") → ผลลัพธ์กรองให้ทันที
3. ใช้ตัวกรองด้านบน:
   - **แท็บหมวดหมู่** (แถวปุ่มใต้ช่องค้นหา) — คลิกครั้งเดียวเพื่อดูเฉพาะหมวดนั้น เช่น เครื่องเขียน, กระดาษและสมุด,
     แฟ้มและจัดเก็บ (ปุ่ม **"ทั้งหมด"** จะกลับไปดูทุกรายการ)
   - **ขนาด** (เมนูแบบเลื่อนลง) เช่น A4, A5
4. ช่อง **"เรียงลำดับ"** เลือกได้: ตามลำดับรายการ / ชื่อ ก-ฮ / ราคา น้อย-มาก / ราคา มาก-น้อย

### 2.2 ตะกร้าสินค้า
- กดปุ่ม **"เพิ่มลงตะกร้า"** ที่การ์ดสินค้า (หรือปุ่ม `+`)
- เปิดตะกร้าได้ 2 แบบ: **แถบด้านข้าง (Drawer)** หรือ **หน้าตะกร้าเต็ม**
- ในตะกร้าปรับ **จำนวน** (`+` / `-`), **ลบรายการ**, และ **เปิด/ปิด VAT 7%** ได้
- ตะกร้าจะ **คงอยู่แม้รีเฟรชหน้า** (เก็บในเบราว์เซอร์)

### 2.3 สร้างใบขออนุมัติสั่งซื้อ
1. ไปที่หน้าตะกร้า → กดปุ่ม **"สร้างใบรายการขออนุมัติสั่งซื้อ"**
2. กรอกข้อมูลเพียง 2 ช่อง:
   - **ชื่อผู้ขอ** (ชื่อ-นามสกุลผู้ขออนุมัติ)
   - **หน่วยงาน / แผนก** (เช่น งานพัสดุ, แผนกวิชาช่างไฟฟ้า)
3. เปิด/ปิด **VAT 7%** ได้ที่หน้าตะกร้า — ถ้าเปิด เอกสารจะแสดง “รวมค่าวัสดุ”, “ภาษีมูลค่าเพิ่ม 7%” และ “รวมทั้งสิ้น”
4. เลือก **แบบอักษรเอกสาร** (มุมขวาบน) ได้ 2 แบบ และระบบจำค่าไว้:
   - **TH Sarabun New (ราชการ)** — ค่าเริ่มต้น ใช้สำหรับเอกสารราชการ
   - **Sarabun** — หน้าตาเหมือนไฟล์ `Expense_Estimation_Form.xlsx` เป๊ะ
5. ดู **ตัวอย่างหน้า A4** ทางขวา แล้วกด **"ดาวน์โหลด PDF"**
   - รูปแบบเดียวกับไฟล์ **Expense_Estimation_Form.xlsx**: แถบหัวเรื่องสีน้ำเงิน **"ประมาณการค่าใช้จ่าย (ค่าใช้สอย/ค่าตอบแทน/ค่าวัสดุ)"**
   - ใต้แถบหัวเรื่องแสดง **ชื่อผู้ขอ / หน่วยงาน-แผนก** ที่กรอกไว้
   - มุมขวาบนมี **เลขที่เอกสาร** (เช่น `PR-2569-1110-001`) และ **วันที่ภาษาไทย** (ค่าเริ่มต้น = วันนี้)
     เลขออกจากฐานข้อมูลกลาง (MongoDB) จึงไม่ซ้ำแม้ออกใบจากหลายเครื่อง
     ใบเดิมจะได้เลขเดิมเสมอ (ดาวน์โหลดซ้ำก็เลขเดิม) แต่ถ้าเปลี่ยนรายการในตะกร้าจะเป็นใบใหม่และได้เลขใหม่
   - หัวข้อ **"ความสอดคล้องกับนโยบาย"** 5 รายการ พร้อมช่องติ๊กให้ทำเครื่องหมายบนกระดาษ:
     1. ปรัชญาเศรษฐกิจพอเพียง (ด้านที่ 1–5)
     2. นโยบายการพัฒนาการศึกษา กระทรวงศึกษาธิการ (นโยบายที่ 1–11)
     3. มาตรฐานการประกันคุณภาพภายในของ สมศ. (มาตรฐานที่ 1–7)
     4. ยุทธศาสตร์ของ สอศ. (ยุทธศาสตร์ที่ 1–4)
     5. ยุทธศาสตร์การพัฒนาจังหวัดอุดรธานี (ยุทธศาสตร์ที่ 1–6)
   - ตาราง 7 คอลัมน์: ลำดับที่ / รายการ / จำนวน / หน่วย / ราคา-หน่วย / รวมเงิน / หมายเหตุ (20 แถวเหมือนแบบฟอร์ม)
   - แถวล่างสุดคือ **"รวมค่าวัสดุ"** สีเหลือง (เอกสารไม่มีช่องลงนาม ไม่มีเลขที่เอกสาร และไม่มีบรรทัด "(ตัวอักษร)")
   - หน้าจอที่เห็น = ไฟล์ PDF ที่ได้ (WYSIWYG) — ถ้ามีเกิน 20 แถวจะขึ้น **หน้าใหม่ที่หน้าตาเหมือนหน้าแรกทั้งหน้า**
     แล้วต่อด้วยแถว 21, 22, ... (เลขลำดับต่อเนื่อง ยอดรวมอยู่หน้าสุดท้าย)
6. ไม่ต้องรอฟอนต์เอง ระบบรอฟอนต์ที่เลือกโหลดเสร็จก่อนสร้าง PDF ให้อัตโนมัติ

### 2.4 ดูทำเนียบบุคลากร
- กดเมนู **"ทำเนียบบุคลากร"** บนแถบนำทาง → เห็นรายชื่อและตำแหน่งของบุคลากรงานพัสดุ
- รายชื่อชุดเดียวกันนี้แสดงอยู่ที่ส่วนท้ายของทุกหน้า (Footer)
- ผู้ใช้ทั่วไปดูได้อย่างเดียว (ปุ่มเพิ่ม/แก้ไข/ลบจะแสดงเฉพาะแอดมินที่ล็อกอินแล้ว)

### 2.5 ธีมสว่าง / มืด
- ค่าเริ่มต้นเป็น **โหมดสว่าง**
- กดปุ่มพระจันทร์/พระอาทิตย์บนแถบเมนูเพื่อสลับเป็น **Dark mode** (ระบบจำค่าไว้)

## 3. การเข้าสู่ระบบเป็นแอดมิน

1. กดเมนู **"ผู้ดูแลระบบ"** บนแถบนำทาง
2. กดปุ่ม **"Sign in with Google"** แล้วเลือกบัญชี Google ที่เป็น **อีเมลแอดมิน**
3. ถ้าล็อกอินด้วยอีเมลอื่น ระบบจะ **ปฏิเสธ** และแจ้งเตือน (อนุญาตเฉพาะอีเมลแอดมินเท่านั้น)

**โหมดทดสอบบนเครื่อง (เฉพาะนักพัฒนา):**
- ถ้าเปิดเว็บที่ `http://localhost` จะมีปุ่ม **"เข้าสู่ระบบแบบโลคอล"** ให้กดทดสอบได้โดยไม่ต้องใช้ Google
- ปุ่มนี้ **จะไม่แสดง** บนเว็บจริงที่ deploy แล้ว

> ถ้าหน้าล็อกอินไม่มีปุ่ม Google เลย แปลว่ายังไม่ได้ตั้งค่า `VITE_GOOGLE_CLIENT_ID`
> (ให้ผู้ดูแลระบบตั้งค่าให้ก่อน — ดู [คู่มือติดตั้ง](./คู่มือติดตั้งและส่งมอบระบบ.md) หัวข้อ 6)

## 4. การจัดการสินค้า (สำหรับแอดมิน)

หลังล็อกอินเข้า **ผู้ดูแลระบบ** จะเห็นหน้าจัดการสินค้า ประกอบด้วยช่องค้นหา, ปุ่ม **"เพิ่มสินค้าใหม่"**,
ปุ่ม **"คืนค่าตั้งต้น"** และตารางสินค้าทั้งหมด

### 4.1 เพิ่มสินค้าใหม่
1. กด **"เพิ่มสินค้าใหม่"**
2. กรอกข้อมูล: **ชื่อสินค้า, ชนิด/หมวดหมู่, ขนาด, ราคา, รายละเอียด**
3. อัปโหลด **รูปสินค้า** (ถ้ามี) — ระบบจะ **ย่อและบีบอัดเป็น JPEG** ให้อัตโนมัติ (ไม่ต้องย่อเอง)
4. กด **"บันทึก"** → สินค้าจะขึ้นในแคตตาล็อกทันทีสำหรับผู้ใช้ทุกคน

### 4.2 แก้ไข / ลบสินค้า
- พิมพ์ชื่อในช่องค้นหาหรือเลือกจากตาราง
- กด **"แก้ไข"** → แก้ข้อมูลแล้วบันทึก (สินค้าที่เคยแก้จะมีป้าย **"แก้ไข"**)
- กด **"ลบ"** → ยืนยันในกล่องข้อความ → ลบออกจากฐานข้อมูลถาวร

### 4.3 นำเข้าข้อมูลตั้งต้น / คืนค่าตั้งต้น
| ปุ่ม | ทำอะไร | ข้อควรระวัง |
| --- | --- | --- |
| **นำเข้าข้อมูลตั้งต้น** | เขียนสินค้าตั้งต้น **252 รายการ** ลงฐานข้อมูล (ใช้เมื่อฐานข้อมูลยังว่าง) | ถ้ามีข้อมูลอยู่แล้วจะเขียนทับ |
| **คืนค่าตั้งต้น** | เขียนทับ **สินค้าทั้งหมด** ด้วยข้อมูลตั้งต้น 252 รายการ | ⚠️ สินค้าที่เพิ่ม/แก้ไข/ลบไว้จะ **หายทั้งหมด** |

> ระบบจะใส่ข้อมูลตั้งต้นให้ **อัตโนมัติครั้งแรก** เมื่อฐานข้อมูลว่าง จึงมักไม่ต้องกดเอง
> แต่ถ้าเคยลบข้อมูลออกหมดและอยากเริ่มใหม่ ก็กดปุ่มนี้ได้

### 4.4 แบนเนอร์สีเหลือง "ข้อมูลสำรอง" คืออะไร
ถ้าเห็นแบนเนอร์สีเหลืองในแคตตาล็อก/หน้าผู้ดูแล แปลว่าเว็บ **ยังดึงข้อมูลจากฐานข้อมูลไม่ได้** จึงแสดงข้อมูลตั้งต้นที่ฝังมากับเว็บแทน
สาเหตุที่พบบ่อย:
- ฐานข้อมูลยังว่าง → กด **"นำเข้าข้อมูลตั้งต้น"**
- การเชื่อมต่อฐานข้อมูลผิดพลาด (ที่อยู่/รหัสผ่าน/สิทธิ์เครือข่าย) → แจ้งผู้ดูแลระบบ

### 4.5 จัดการทำเนียบบุคลากร
เมนู **"ทำเนียบบุคลากร"** ใช้เก็บรายชื่อและตำแหน่งของบุคลากรงานพัสดุ (ไม่ต้องแก้โค้ด)
ข้อมูลเก็บใน MongoDB คอลเลกชัน `personnel` → แสดงในหน้าเว็บและ Footer ทันทีสำหรับทุกคน

1. กดเมนู **"ทำเนียบบุคลากร"** (ต้องล็อกอินเป็นแอดมินก่อน)
2. กรอก **ชื่อ-นามสกุล** และ **ตำแหน่ง / หน้าที่** (เช่น "นายสมชาย ใจดี" / "หัวหน้างานพัสดุ")
3. กด **"เพิ่มบุคลากร"** → รายชื่อจะขึ้นในรายการด้านล่างและใน Footer
4. กดไอคอน **ดินสอ** เพื่อแก้ไข → แก้ข้อความ → กด **"บันทึกการแก้ไข"** (หรือกด **"ยกเลิก"** เพื่อออกจากโหมดแก้ไข)
5. กดไอคอน **ถังขยะ** เพื่อลบ → ยืนยันในกล่องข้อความ

> รายชื่อจะเรียงตามลำดับที่เพิ่ม (รายการใหม่ต่อท้าย) และไม่มีการจำกัดจำนวน
> ถ้าฐานข้อมูลยังไม่เชื่อมต่อ หน้าจะแจ้งเตือนและยังเพิ่มรายชื่อไม่ได้

## 5. ปัญหาที่พบบ่อย (FAQ)

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
| --- | --- | --- |
| เห็นแบนเนอร์เหลือง "ข้อมูลสำรอง" | ฐานข้อมูลว่าง หรือเชื่อมต่อไม่ได้ | กด "นำเข้าข้อมูลตั้งต้น" / แจ้งผู้ดูแลระบบตรวจ `MONGODB_URI` |
| กดล็อกอินแล้วเข้าไม่ได้ | อีเมลไม่ตรงกับอีเมลแอดมิน | ใช้อีเมลที่ตั้งเป็น `ADMIN_EMAIL` เท่านั้น |
| ไม่มีปุ่ม Sign in with Google | ยังไม่ตั้ง `VITE_GOOGLE_CLIENT_ID` | ให้ผู้ดูแลระบบตั้งค่า + เพิ่มโดเมนใน Google Cloud |
| กดบันทึกสินค้าแล้วขึ้น error | ยังไม่ล็อกอิน / เซสชันหมดอายุ / API ผิดพลาด | ล็อกอินใหม่แล้วลองอีกครั้ง |
| PDF ฟอนต์เพี้ยน/ตัวหนังสือหาย | ฟอนต์ยังโหลดไม่เสร็จตอนกดดาวน์โหลด | รอสักครู่แล้วกดดาวน์โหลดใหม่ |
| รูปสินค้าไม่ขึ้น | รูปใหญ่เกินไป หรืออัปโหลดไม่สำเร็จ | ลองอัปโหลดรูปใหม่ (ระบบย่อให้เอง) |
| เพิ่มรายชื่อในทำเนียบบุคลากรไม่ได้ | ยังไม่ล็อกอินแอดมิน หรือฐานข้อมูลไม่พร้อม | ล็อกอินด้วยอีเมลแอดมิน / ตรวจ `MONGODB_URI` |
| Footer ไม่แสดงรายชื่อบุคลากร | ยังไม่มีข้อมูลในฐานข้อมูล | แอดมินเพิ่มรายชื่อที่เมนู "ทำเนียบบุคลากร" |

## 6. ข้อควรระวัง

- **อย่าแชร์รหัสผ่านฐานข้อมูล (MongoDB) หรือ Client ID/Secret ให้ผู้อื่น**
- ปุ่ม **"คืนค่าตั้งต้น"** ทำให้ข้อมูลที่แก้ไว้หายถาวร — ควรสำรองก่อนถ้าข้อมูลสำคัญ
- การลบรายชื่อในทำเนียบบุคลากรมีผลทันทีกับทุกคน (ไม่มีปุ่มย้อนกลับ)
- ระบบนี้ **ไม่มีการชำระเงิน/ออกใบกำกับภาษีอย่างเป็นทางการ** เป็นเพียงเครื่องมือสร้างเอกสารขออนุมัติสั่งซื้อ
- ข้อมูลสินค้าเป็นตัวอย่างจากไฟล์ Excel ควรตรวจสอบราคาให้ตรงกับความเป็นจริงก่อนใช้งาน
